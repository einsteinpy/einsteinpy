Geodesic module
===============

This module contains classes for computing and analyzing geodesics (the paths that particles 
follow through curved spacetime) in general relativity. Geodesics describe the motion of 
both massive particles (time-like geodesics) and massless particles like photons (null geodesics).

Key features include:

- **Geodesic trajectory calculation**: Compute the path of particles through curved spacetime
- **Multiple coordinate system support**: Work with results in various coordinate systems
- **Visualization tools**: Plot geodesic trajectories in both static and interactive formats
- **Integration with metrics**: Seamlessly work with various spacetime metrics

This module is essential for simulating black hole lensing, particle trajectories near 
compact objects, and testing predictions of general relativity.
