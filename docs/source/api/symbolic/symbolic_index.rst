Symbolic Relativity Module
==========================

This module provides comprehensive tools for performing symbolic calculations in general 
relativity using SymPy. It enables analytical derivations of tensors, connections, and 
curvature quantities that describe the geometry of spacetime.

The module supports:

- **Tensor operations**: Work with covariant, contravariant, and mixed tensors
- **Curvature tensors**: Compute Riemann, Ricci, Einstein, and Weyl tensors
- **Christoffel symbols**: Calculate connection coefficients for any metric
- **Tensor algebra**: Perform symbolic operations on relativistic tensors
- **Predefined metrics**: Quick access to common spacetime metrics like Schwarzschild, Kerr, and FLRW

This module is particularly useful for:

- Deriving equations of motion analytically
- Verifying theoretical results
- Exploring new metrics and spacetimes
- Educational purposes in relativistic physics
