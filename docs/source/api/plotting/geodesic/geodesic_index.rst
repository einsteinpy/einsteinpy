Plotting Geodesics
==================

This module provides visualization tools for geodesic trajectories in curved spacetime. 
It includes both static plotting capabilities (using Matplotlib) and interactive plotting 
options (using Plotly) for exploring geodesic paths in 2D and 3D.

Features include:

- **StaticGeodesicPlotter**: Create publication-quality static plots of geodesic trajectories
- **InteractiveGeodesicPlotter**: Create interactive 3D visualizations that can be rotated and zoomed
- **Aspect ratio control**: Ensure proper proportionality in visualizations
- **Multiple coordinate system support**: Plot geodesics in various coordinate representations

These tools are essential for visualizing black hole lensing effects, particle trajectories, 
and understanding the geometric properties of curved spacetime.
